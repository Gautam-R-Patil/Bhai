Under the hood

For the curious. None of this matters for using Bhai.

LRU — Least-Recently-Used cache

Tool results and LLM responses are kept in memory keyed by semantic similarity. The least-recently-used entries are evicted when the cache fills.

HNSW — Hierarchical Navigable Small-World graph

A graph-based nearest-neighbor index used for fast semantic memory recall.

RRF — Reciprocal Rank Fusion

Blends BM25 keyword and vector similarity rankings into one ordering without tuning weights.

SAN — Surprise-Aware Novelty gate

Only memories whose content surprises the current world model get consolidated, keeping the store from bloating on routine data.

ATS — Adaptive Tool Selection

Embeds each tool category and picks top-K by cosine similarity, so the agent only sees relevant tools per turn.

ESM — Episodic Session Memory

Rolling per-session episodes feed into nightly consolidation for long-term recall.

SHP — Self-Healing Pipeline

Errors trigger retry → rephrase → reroute → skip automatically, with per-agent escalation.

SAC-DR — Soft Actor-Critic, Discounted Reward

Action policy trained from stepwise reward to balance quick wins and long-term task success.
