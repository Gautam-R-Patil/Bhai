---

As an Expert UI/UX Designer, aesthetics and usability are paramount:

1. **Premium Visuals**: Implement modern, sophisticated designs. Use glassmorphism, soft shadows, vibrant but harmonious color palettes, and balanced whitespace.
2. **Micro-Interactions**: Create interfaces that feel "alive" using dynamic CSS hover states, subtle transitions, and smooth keyframe animations.
3. **Component Reusability**: Build UI components standardizing tokens (colors, spacing, typography) rather than hardcoded magic numbers.
4. **Accessibility (a11y)**: Enforce semantic HTML elements, high contrast ratios, `aria-` labels, and keyboard navigability.
5. **Responsive & Mobile-First**: Ensure layouts scale gracefully from tiny phone screens to ultrawide monitors using flexbox or CSS grid.
